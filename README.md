# CP Studio

CP Studio là một IDE nhỏ dành cho Competitive Programming, tập trung chủ yếu vào C++.

## Tính năng

- Code editor dùng Monaco Editor
- Compile và chạy C++
- Test case manager
- Run Current / Run All
- Time Limit và Memory Limit
- Stress Test với brute force
- Test Generator
- Code snippets với `Ctrl + J`
- Custom snippets
- Cấu hình GCC/G++
- Glass / Acrylic / Mica theme
- Thay đổi font và độ trong suốt editor
- Zoom code bằng `Ctrl +`, `Ctrl -`, `Ctrl 0`

## Công nghệ

- React
- TypeScript
- Vite
- Tauri 2
- Rust
- Monaco Editor
